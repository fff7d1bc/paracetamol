# Public synthetic scenario provenance

The off-replay request is recovered only from the `request` object of the known
synthetic `tools-none-replay.json` fixture in the November 3 replay experiment.
The source artifact SHA-256 was
`342fe73d55e1a79eb203aab87cf486579a8705787dc514840a1ab56dee708935`.
It contains an invented ALDER record and a nested lookup tool, not project code,
personal traffic, or a third-party task. The raw response, report, request IDs,
timestamps and infrastructure metadata are not copied. The opaque tool-call ID
is retained because changing it could change prompt tokenization. The model is
supplied at runtime, JSON whitespace is normalized, and the five seeds plus
temperature-zero wrapper are newly public definitions. This is not a claim to
recover a lost runner, rendered prompt bytes, or a historical six-case manifest.
The answer oracle accepts surrounding whitespace only, never duplicate values,
reasoning tags or explanation. All six cases require natural completion.

All other inputs and generators here are newly authored public synthetic tests.
No other private experiment files, codebases or archived coding tasks were read
or copied. Distributed numeric record tables are generated by the versioned
algorithm in scenarios.go; their sizes are calibrated using observed input
tokens, not assumed character/token ratios. Oracle failures fail the case.
Missing token, cache or native-slot evidence blocks the affected coverage.

Version 2 adds explicit fixed slot preparation before Lifecycle and Prefill,
independently identified by `slot-init.v1`. The initial read-only probe requires
exactly four distinct idle slot IDs but permits unused slots to omit counters.
Four ordered requests then target slots 0 through 3 with original fixed markers,
thinking off, seed 42, cache disabled and a 128-token output budget. Each requires
natural completion and its exact marker through the normal correlated gateway
transport. The subsequent strict probe must observe measured prompt counters for
all four slots; missing counters are never replaced with zero. This preparation
is new versioned input, not a recovered historical conditioning sequence.

The cache-conditioning family/slot/depth sequence comes from the known synthetic
October 26 cache experiment and the public full-span correction record. Only its
synthetic prompt-generator section and scalar fixture metadata were inspected;
the old transport, process/memory guard implementation and runner are not copied.
The source probe artifact SHA-256 was
`67e412f79f37992c176def74d3e0ab51e588ef657e5cc0a6c78144642e45750c`.

epsilon/0 at 74K, epsilon/0 extending to approximately 114K, then zeta/2 at 16K.
Near-pool occupancy must be observed independently. This sequence conditions the
maintained reproducer; it does not prove a particular physical k-pool span or an

Four worker markers are new synthetic inputs and do not imply measured overlap.
